
# Encoding Requirements Classes (Clause)

`ogc.api.common.part1.clauses.encodings` *v1.0.0*

Clause 10 of OGC API - Common - Part 1: Core: overview of the HTML and JSON encoding requirements classes, which are its subclauses 10.2 and 10.3.

[*Status*](http://www.opengis.net/def/status): Stable

## Description

# Overview

This clause specifies two requirements classes for encodings that may be used by an OGC Web API
implementation. These encodings are commonly used for spatial data on the web applications:

- HTML
- JSON

Neither of these encodings are mandatory. An implementation of the OGC API — Common Standard may
implement one, both, or none of them. Other encodings are possible.
